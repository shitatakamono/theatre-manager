# 競合検知 v1 手動確認

本番データではなく、ローカルEmulatorまたは確認専用projectで実施する。

1. Ownerでログインしたブラウザと、Editorでログインした別ブラウザ（または別プロファイル）を開く。
2. 両方で同じprojectの「チラシ・ポスター」を開き、同じ「チラシ」編集drawerを開く。
3. Owner側で部数を変更して保存する。
4. Editor側は画面を再読込せず、別の部数を入力して保存する。
5. Editor側に競合警告が表示され、drawerと入力内容が残ることを確認する。
6. FirestoreでOwnerの部数と`revisions.flyer`だけが更新されていることを確認する。
7. 更新履歴にOwnerの1件だけが追加され、Editorの履歴がないことを確認する。
8. Editor側の「最新の内容を読み込む」を押し、未保存内容が失われる確認ダイアログを承認する。
9. Ownerが保存した最新内容が表示されることを確認する。

別セクション確認では、Ownerがチラシ、Editorが会計を同時に開いて順に保存し、両方成功することを確認する。
