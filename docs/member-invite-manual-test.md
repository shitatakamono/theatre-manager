# メール招待 v1 手動テスト

1. Ownerで対象公演の「メンバー」を開く。
2. 未参加のGoogleアカウントのメールアドレスをEditorとして招待する。
3. 「招待中」にメールアドレス、Editor、未参加が表示されることを確認する。
4. シークレットウィンドウで招待先のGoogleアカウントを使ってSeisakuBoardへログインする。
5. 「招待されている公演へ参加しました」と表示され、ログアウトや再ログインなしで公演一覧に対象公演が表示されることを確認する。
6. 公演を開き、通常の編集と保存ができることを確認する。
7. Owner側のメンバー画面にGoogle表示名、メールアドレス、Editorが表示されることを確認する。
8. 別の招待を作成後、Ownerが「招待を取り消す」を実行し、招待先アカウントでログインしても参加できないことを確認する。

本番確認時は、既存メンバーではないテスト用Googleアカウントと、テスト後に削除可能な公演を使用する。
